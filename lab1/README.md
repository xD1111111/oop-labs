# Лабораторна робота №1 з ООП — Dart + Flutter

Номер у журналі: **9**. Відповідно до методички: **В1 = 9 mod 4 = 1**, **В2 = (9 + 1) mod 4 = 2**.

## Що готово

- Головне вікно з пунктами меню «Робота1», «Робота2».
- «Робота1» — діалог з повзунком 1–100, кнопками «Так» і «Відміна». Число відображається в головному вікні тільки після натиснення «Так».
- «Робота2» — два діалогові вікна в окремих модулях: «Далі >», «Відміна» у першому; «< Назад», «Так», «Відміна» у другому.
- Кнопки закриття діалогів поводяться як «Відміна» (код повернення 0).
- Усі діалоги закриваються до відкриття наступних; скасування не змінює результат.
- `lib/main.dart` і 3 незалежні модулі; діаграма імпортів у `docs/DIAGRAM.md`.

## Що потрібно встановити

1. VS Code (у тебе вже є).
2. Flutter SDK + Flutter extension у VS Code: https://docs.flutter.dev/get-started/install/windows/desktop
3. **Для запуску саме Windows-застосунку** також потрібна повна Visual Studio (це не VS Code!) з компонентом **Desktop development with C++**. Увесь код лабораторної пишеться на Dart; C++ потрібен лише для системних інструментів компіляції Flutter Windows: https://docs.flutter.dev/platform-integration/windows/setup

## Як запустити на Windows

1. Розпакуй ZIP, відкрий папку `lab1_oop` у VS Code.
2. У терміналі VS Code виконай:

```powershell
flutter doctor
flutter create --platforms=windows .
flutter pub get
flutter run -d windows
```

Команда `flutter create --platforms=windows .` створює стандартні системні файли для Windows, відсутні в архіві. **Вона не повинна перезаписувати наявні `lib/*.dart` файли** (не використовуй прапорець `--overwrite`).

Можна також двічі клацнути `START_WINDOWS.bat`; він виконує команди створення файлів та запуску.
