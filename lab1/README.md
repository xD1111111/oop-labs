# Лабораторна робота №1 з ООП

**Тема:** Знайомство з середовищем розробки та складанням модульних
проєктів програм.

**Номер у журналі:** 9\
**Мова програмування:** Dart\
**Фреймворк:** Flutter\
**Середовище розробки:** Visual Studio Code

## Варіант

Відповідно до методичних вказівок для номера 9:

-   `B1 = 9 mod 4 = 1`;
-   `B2 = (9 + 1) mod 4 = 2`.

Робота реалізована на Dart + Flutter замість C++ за погодженням із
викладачем.

## Що реалізовано

Програма має головне вікно з двома пунктами: **«Робота1»** та
**«Робота2»**.

### Робота 1

-   Відкривається діалогове вікно для вибору числа від 1 до 100.
-   У діалозі є кнопки підтвердження **«Так»** та скасування
    **«Відміна»**.
-   Після підтвердження вибране число відображається в головному вікні.
-   Якщо діалог скасувати, вибір не підтверджується.

### Робота 2

-   Реалізовано послідовність із двох діалогових вікон.
-   Для переходу між вікнами та повернення передбачено відповідні
    кнопки.
-   Діалоги відкриваються послідовно, без одночасного накладання кількох
    вікон.

## Структура проєкту

``` text
lab1/

│   ├── main.dart

│   ├── module2.dart
```

Основний файл програми --- `lib/main.dart`. Додаткові частини реалізації
винесені в окремі файли `module1.dart`, `module2.dart` та
`module3.dart`.

## Як запустити програму на Windows

Потрібно мати встановлені Flutter SDK, Visual Studio Code та компоненти
Visual Studio для розробки Windows-застосунків.

1.  Відкрити папку `lab1` у Visual Studio Code.
2.  Відкрити термінал у цій папці.
3.  Виконати команди:

``` powershell
flutter doctor
flutter pub get
flutter run -d windows
```

Якщо залежності вже встановлені, достатньо виконати:

``` powershell
flutter run -d windows
```

Також для запуску можна використати файл `START_WINDOWS.bat`.

## Перевірка роботи

Під час перевірки програми потрібно продемонструвати:

1.  Запуск головного вікна лабораторної роботи.
2.  Відкриття пункту **«Робота1»** та вибір числа в межах від 1 до 100.
3.  Підтвердження вибору та відображення числа в головному вікні.
4.  Скасування вибору без підтвердження.
5.  Відкриття пункту **«Робота2»** і перехід між двома діалоговими
    вікнами.
