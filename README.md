# Лабораторні роботи з об'єктно-орієнтованого програмування

Репозиторій містить мої лабораторні роботи з дисципліни
**«Об'єктно-орієнтоване програмування»**.

Для виконання робіт використовую **Dart** та **Flutter** (замість C++,
за погодженням із викладачем). Розробка ведеться у Visual Studio Code.

## Структура репозиторію

``` text
oop-labs/
├── lab1/       # Лабораторна робота №1
├── lab2/       # Лабораторна робота №2 
├── lab3/       # Лабораторна робота №3 
├── lab4/       # Лабораторна робота №4 
├── lab5/       # Лабораторна робота №5 (буде додано)
├── lab6/       # Лабораторна робота №6 (буде додано)
└── README.md   # Загальна інформація та таблиця робіт
```

## Використані інструменти

-   **Мова програмування:** Dart
-   **Фреймворк:** Flutter
-   **Середовище розробки:** Visual Studio Code
-   **Система контролю версій:** Git та GitHub
